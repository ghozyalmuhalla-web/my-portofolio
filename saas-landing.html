Masih Ada Pertanyaan?

Bagaimana cara kerja batas token pada Aether AI? expand_more
Token dihitung berdasarkan volume teks input dan output yang dikirimkan ke model AI melalui gateway kami. Jika kuota Anda habis, Anda dapat melakukan top-up instan atau menanti siklus tagihan berikutnya.
Apakah saya bisa menggunakan API model saya sendiri? expand_more
Ya, tentu saja. Aether AI mendukung integrasi API pihak ketiga (Custom BYOK) seperti OpenAI, Anthropic, dan server model Open Source lokal Anda (Ollama/vLLM).
Apakah ada kontrak jangka panjang? expand_more
Tidak ada kontrak. Paket berbayar kami ditagih secara bulanan atau tahunan, dan Anda bisa membatalkannya kapan saja tanpa denda atau biaya tambahan apa pun.
